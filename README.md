# 🚀 Aditya Thete - AI Engineer Portfolio Website

A modern, high-performance portfolio website tailored for a **Machine Learning & Generative AI Engineer** profile, featuring a built-in interactive **Admin Panel** for effortless content management, and an interactive **"Ask AI Persona"** terminal simulator.

## 🌟 Highlights & Features

- **Cyber/AI Aesthetic**: Sleek dark mode design with glowing emerald and cyan accents, neural particle network background, and glassmorphic cards.
- **Dynamic Content Engine**: All profile data, projects, metrics, skills, timeline, and education load dynamically with instant local persistence.
- **Dedicated Admin Panel (`admin.html`)**:
  - Protected by a secure PIN (`aditya2026`).
  - Manage all personal info, technical skills matrix, featured projects, work experience, education, and certifications.
  - One-click **"Export data.json"** to download updated configurations.
  - One-click **"Import data.json"** and **"Reset to Defaults"**.
- **Interactive "Ask AI About Aditya" Simulator**:
  - Live terminal-style assistant grounded in Aditya's real resume data (RAG pipelines, LangGraph agents, medical chatbot, etc.).
- **Interactive Project Filtering**: Filter projects seamlessly across Generative AI, NLP & Deep Learning, and Machine Learning.
- **Zero-Dependency Architecture**: Runs in any modern browser without needing Node.js or build steps.
- **100% Free Deployment Ready**: Deploy in 60 seconds on **Netlify Drop**, **GitHub Pages**, or **Vercel**.

## 🚀 Quick Start (Local Testing)

Open your terminal or PowerShell in this folder:

```powershell
python -m http.server 8000
```

- Open **`http://localhost:8000`** to view your portfolio.
- Open **`http://localhost:8000/admin.html`** to access the Admin Panel.
  - **Default PIN**: `aditya2026`
